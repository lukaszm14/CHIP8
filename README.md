# CHIP-8 Emulator

## Goal

Educational CHIP-8 emulator written in C++.

The main goal of this project is to practice software engineering, modern C++ practise and emulator development.

## Technologies

- C++17
- CMake
- Git
- SDL2 (planned)

## Planned features

- ROM loading and memory management
- CPU emulation
- Graphics
- Keyboard
- Timers

## Learning notes

This project is implemented as a learning exercise.

AI tools (ChatGPT) are used for code reviews, explanations of C++ concepts and discussions about design decisions. All implementation and architectural decisions are made and integrated manually.
